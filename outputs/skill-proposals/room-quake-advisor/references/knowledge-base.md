# 根拠と事例の選び方

## 2種類の知識

| 種別 | 役割 | 使うときの注意 |
| --- | --- | --- |
| 対策ルール | 家具等の動きと対策の一般的な根拠 | 適用対象・成立条件・資料の範囲を残す |
| 被災・実験事例 | 実際に記録された動きや被害の具体例 | この部屋で同じことが起きる確率を示す資料とは限らない |

この設計案には出典の案内を含めるが、収集済みの被災写真データセットは含めない。事例が未登録なら結果は「公的資料に基づく一般的な想定」とし、事例照合済みと表示しない。

## 初期の出典

確認日：2026-09-15。利用時は引用する主張に対応する本文を確認する。確認済みのローカル資料を使う場合は、出典・版・該当箇所を示す。本文を取得できなければその確認限界を残す。

- `jma-intensity` — [気象庁震度階級関連解説表](https://www.jma.go.jp/jma/kishou/know/shindo/kaisetsu.html)。揺れと室内状況を結び付ける一般的な資料。地表の震度と建物内の揺れの違い、被害には幅があることを適用条件に含める。個別家具の転倒確率の表として扱わない。
- `tfd-furniture` — [東京消防庁：家具類の転倒・落下・移動防止対策ハンドブック](https://www.tfd.metro.tokyo.lg.jp/learning/elib/kagutenhandbook.html)（令和6年1月）。家具・家電・オフィス家具の配置、収納、固定の助言を確認する入口。実際の固定方法を助言するときは該当する章と設置条件を読む。
- `tfd-layout` — [東京消防庁：第6章 地震に備える](https://www.tfd.metro.tokyo.lg.jp/ts/bfc_manual/instructor/cp6.html)。家具の配置、通路との関係、収納の基本を確認する資料。
- `nied-indoor` — [防災科研：室内空間を中心とした研究の実施項目](https://indoorpj.e-defense.bosai.go.jp/implementation/)。実験・研究資料を探す入口。研究計画の記述を、公開済みの予測モデルや本スキルの精度実証と扱わない。
- `nied-media-terms` — [E－ディフェンス：写真・映像の利用申請手順](https://www.bosai.go.jp/hyogo/research/movie/movie-i.html)。貸出素材の利用目的・編集・第三者提供等の条件を確認する入口。この案には素材の転載や利用許諾は含まれない。

## 事例レコードの最小設計

写真1枚ではなく、同じ部屋・同じ地震または同じ実験条件を1つの事例とする。同じ動画の連続フレームを独立した被害事例として数えない。

| フィールド | 記録内容 |
| --- | --- |
| `case_id`, `event_or_experiment_id`, `room_id` | 一意のIDと、写真をまとめる単位 |
| `case_type` | `real_event` / `experiment`。説明用画像は別に管理する |
| `source` | 発行者・資料名・URL・版または日付・ページや映像時刻 |
| `media` | 写真や映像への参照、地震前／後／不明、同一視点かどうか |
| `usage` | 利用条件の出典、許可された用途、必要な表記、確認状況 |
| `context` | 用途・階数・構造・揺れ。地表観測、床応答、実験入力を区別 |
| `objects` | 対象の種類、判明している寸法・支持面・固定・内容物・配置 |
| `observed_outcomes` | 転倒・落下・移動・破損等の記録と、それを示す写真や本文 |
| `conditions_and_limits` | 不明な条件、再現できない部分、対策前後の比較条件 |
| `review` | AI抽出か人が確認したか、確認日、訂正履歴 |

不明値は `null` または明示的な `unknown` とする。「記載なし」を「固定なし」「被害なし」に置き換えない。被害原因が本文に記録されていない場合は、観察された状態と原因の仮説を分ける。

対策ルールもIDを持ち、主張・適用条件・助言・出典箇所を保存する。事例画像を解析して作った説明は、原資料に書かれた事実と区別する。利用条件不明の画像は許諾済みとして配布・転載・外部解析に回さず、確認が必要な候補として扱う。

## 検索と照合

1. 家具の種類と動きに関係する条件で候補を絞る。例：背の高い収納、床置き、固定状態、棚上の物、ベッド・出入口との関係。
2. 揺れの測定位置・階・支持面・固定等を比較する。不明な値を一致と数えない。固定済みの家具に未固定家具の事例を使う場合は、条件が異なる参考例と明示する。
3. 画像の外観や文章の意味の類似性は補助に使う。被災後画像は見た目が大きく変わるため、画像の近さだけで検索を決めない。
4. 原写真・映像・本文で候補を確認し、「一致した条件」「異なる条件」「不明な条件」「支えられる主張」を残す。写真を閲覧していなければ画像を照合したと書かない。
5. 適切な事例がない場合は、無理に採用せず公的資料の一般則へ戻る。出典自体を確認できない主張は裏付け済みとしない。

少数の事例ならJSON等への条件検索から始める。検索に使う特徴が固まってから、件数・速度に応じて全文検索や意味検索を追加する。ベクトル類似度は検索順位用であり、被害確率や安全スコアには変換しない。

## 知識ベースを増やすとき

被害の大きい写真だけを集めると、同じ条件で被害が小さかった例が抜ける。可能なら無被害・軽微な被害、固定あり・なし、同じ室内の加震前後を含める。異なる地震・実験・部屋の資料で検証できるようグループIDを保つ。

事例数が増えても自動的に予測精度は保証されない。定量的な予測を追加する段階では、揺れ・固定・家具特性を含むデータと、未使用の地震や部屋を使った評価が別途必要になる。
