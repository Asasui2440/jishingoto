# 人物の行動が見える挿絵
制作方法：内蔵 image_gen。表示時のAPI呼び出しはありません。

ホームの room-v3.webp を画風の参考に、物だけの図を人物入りに置き換えました。細い輪郭、控えめな色、微細な線の揺れを指定しています。AIで制作した固定素材です。

生成プロンプト・元画像の対応は [prompts.json](prompts.json)。同じフォルダに採用した元PNGを保存しています。画面用WebPは [表示用素材フォルダ](../../../public/illustrations/textbook/) に保存しています。

| 場面 | 表示用ファイル |
|---|---|
| 出口を確かめる | open-exit-v2.webp |
| 危険な建物から離れる | damaged-exit-v2.webp |
| コンロの火を止める | kitchen-v2.webp |
| 元栓を閉める | gas-valve-v2.webp |
| まくらで頭・首を守る | bed-v2.webp |
| コピー機から離れて身を守る | printer-v2.webp |
| 階段を使う | stairs-v2.webp |
| 職場で待機・情報確認 | office-v2.webp |

高台への避難と在宅での情報確認は、同じタッチの既存の人物入り素材を再利用しています。
