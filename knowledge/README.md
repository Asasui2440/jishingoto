# 地震・洪水ナレッジ

地震・洪水による被害の理解、室内写真の分析、備え・避難の助言に使うための資料集です。公的機関の一次資料を中心に、原典を確認した要約をMarkdownで蓄積します。

**初期収集日：2026-09-15。知識ノート21件。** 原典本文を確認した段階で、専門家によるレビューや予測精度の検証は未実施です。地震の室内写真解析には、下記の7件を接続しています。自動収集・モデル学習は未実装です。

## アプリからの参照

`/api/room/analyze` は、EQ-001・002・003・004・006、CASE-001・002の本文を画像とともに渡し、モデルが各対象の想定・助言に使ったIDを返します。サーバーが出典IDを検証し、台帳の原典URL・確認日と資料の版を付与します。結果は家具の確認画面で観察・条件付き想定・備え・不明点を分けて表示します。

参照対象は[読み込み処理](../src/lib/server/room-knowledge.ts)の一覧で管理します。フォルダへ資料を追加しただけでは解析対象に入りません。参照対象の本文・出典・確認状態を読み込み、未確認の資料や欠落はエラーにします。原典の現在の警報・更新状況を毎回オンラインで確認する機能ではありません。固定サンプルと洪水の画像解析は、この接続の対象外です。Tips・クイズの証言表示は、下記の「被災者の声」の別の公開用データで扱います。

## 使い方

1. 下の索引から対象に合うノートを選びます。
2. 「原典から確認した知識」と「分析・助言への適用」を区別して読みます。
3. ノートの適用条件・限界を確認し、個別の建物・地域に必要な追加情報を調べます。
4. 出典の版を確認します。実際の避難では、自治体・気象庁・河川管理者の最新の発表を確認します。このフォルダは現在の警報・水位・避難所の開設状況を保存するものではありません。

## 被災者の声

[被災者の声の索引](voices/README.md)に、原典を確認した12エピソードを追加しました（2026-09-15）。既存の知識ノート21件とは別に数えます。内閣府の聞き取り記事を要約し、出典・年齢・地域・家族への言及・同居と当日の同行の違い・住まい・支援条件を分かる範囲で記録しています。

行動と被害・困難の関係は、語り手の説明、本人の振り返り、編集上の仮説、判断不可に区分しています。属性の不明欄は補完しません。6件（VOICE-001・002・003・004・005・011）は掲載文と関連先を確認し、7カードを関連するTips・クイズの振り返りへ接続しています。残り6件は掲載候補です。追加質問を設けず、回答の選択肢や教材のテーマで選びます。[掲載・更新手順](../docs/KNOWLEDGE_INTEGRATION.md)を参照してください。[収集記録](voices/COLLECTION_LOG.md)と[収集スキル](../skills/collect-survivor-voices/SKILL.md)を参照してください。

## 蓄積と更新

- [出典台帳](SOURCES.md)：原典URL・版・確認箇所。
- [収集記録](COLLECTION_LOG.md)：収集範囲、確認結果、未収集事項。
- [追加用テンプレート](templates/knowledge-note.md)：新しい知識を追加するときの形式。

1ノート1テーマとし、安定したIDを付けます。同じテーマの改訂は既存ノートを更新し、出典の版と確認日を更新します。異なる災害・実験は別の事例IDにします。同じ調査の複数図表や同じ動画のフレームを、独立した事例として重複計上しません。

`review_status: source_checked` は原典の該当箇所を確認した意味です。査読済み、専門家承認済み、個別住宅の診断済みを意味しません。観察だけで分からない寸法・固定状態・浸水確率等は不明のまま扱い、推測を原典の事実に書き戻しません。

検索例：

```bash
rg -n '固定|落下|出入口' knowledge/earthquake knowledge/cases
rg -n '浸水深|屋内安全確保|未整備' knowledge/flood
rg -n 'source_ids:|checked_at:' knowledge
```
