# 熊本地震の室内被害アンケート

## 原典から確認した知識

東京消防庁が熊本市・益城町・西原村を対象に、2016年9月13日～11月30日に行った調査。

| 項目 | 原典の値 |
| --- | --- |
| 配布・回収 | 配布800世帯、回収407世帯 |
| 住宅属性 | 戸建住宅367世帯。店舗併用住宅・共同住宅等も含む |
| 負傷者 | 確認された負傷者24人 |
| 負傷要因 | 家具類の転倒・落下・移動7人、割れたガラス等の片付け3人 |

出典：[東京消防庁・熊本地震に伴う室内被害の実態調査結果（戸建住宅編）](https://www.tfd.metro.tokyo.lg.jp/content/000011501.pdf)、本文1～5ページ（PDF2～6ページ）。

## 分析・助言への適用（編集上の整理）

家具による負傷と、片付け時の負傷を別の段階として扱う。写真分析では家具の位置だけでなく、破片・収納物の散乱も記録対象にする。

## 適用条件・限界

7人の分母は負傷者24人であり、全407世帯でも一般人口でもない。事後アンケートで、回答者の選択や記憶の影響を受ける。この割合を別の住宅の負傷確率、固定対策の因果的な効果に変換しない。個別住宅の写真・地震動・固定状態を対応させたデータセットは未取得。
