## 各ノートに保存する情報

- 原典URL、掲載者、エピソード番号、本文の該当箇所、災害時期、聞き取り日、確認日。
- 年齢とその時点、原典の性別表記、職業、地域、家族、同居構成、発災時に一緒にいた人、住まい、ペット、支援に関係する条件。
- 経験の要約、行動と被害・困難の関係、根拠と限界、関連するTips・問題・公的指針の候補。

家族の記載がない場合は「不明」であり、独居・子どもなしとは扱いません。家族の存在、平時の同居者、当日の同席者は別です。年代は原典どおりに残し、満年齢や発災時年齢を推測しません。

VOICE-005とVOICE-006は、地域・属性・聞き取り日が一致するため同じ人物の別エピソードの可能性があります。人物の同一性は未確認で、属性を相互に補完せず、独立した2人の証言として集計しません。他の匿名記事も、人口統計の標本として独立性を確認したものではありません。

## 行動と被害の記録区分

| 値 | 意味 |
| --- | --- |
| `source_attributed` | 語り手が、行動・状況と結果の関係を説明している |
| `source_reflection` | 本人による事後の振り返り、または「こうしていれば」という考え |
| `editorial_interpretation` | 原典の経過をもとにした編集上の仮説。確定した被害原因ではない |
| `none` | 被害を起こした行動傾向の記載がない、または判断できない |

どの区分も独立した因果検証済みを意味しません。物的・身体的被害、連絡できない不安、避難準備の難しさなど、結果の種類を明示します。被害を当事者の性格や家族の属性に帰属させず、当時の情報や支援の条件も読みます。

## 確認状態と使い方

`review_status: source_checked` は原典本文を読んで照合した状態です。専門家レビュー、本人による要約確認、アプリ掲載承認とは異なります。VOICE-001・002・003・004・005・011の `publication_status` は、原典・掲載文・関連先を確認した `approved` です。残り6件は `draft` です。掲載文の確認者はCodexで、専門家や証言者本人の承認を意味しません。

各ノートの一般的な「教材への適用」は候補です。実際に表示する範囲はノート末尾の `APP_KNOWLEDGE` ブロックにある掲載文・関連先に限定します。追加・更新は[連携手順](../../docs/KNOWLEDGE_INTEGRATION.md)に従い、再確認・再生成して使います。記録された行動をそのままクイズの正解にせず、津波からの避難を洪水時の屋内待機へ流用するなど、条件の取り違えを避けます。
