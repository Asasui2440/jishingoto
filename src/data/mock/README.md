# OpenAI代替のモックデータ

`OPENAI_MOCK_MODE=true` をサーバーの環境変数に設定すると、既存APIがこのデータを返す。無効なキーが設定済みでもOpenAIへ通信しない。UI・入口・画面遷移は変更しない。`false` または未設定で実APIに戻る。

- `room-analysis.json`: サンプル写真 `public/figma/img/room-risk.jpg` の本棚・窓・出入口を想定した解析レスポンス。設問とチェックリストは従来どおり候補から作られる。
- `room-aftermath.json`: 既存の固定テスト画像レスポンス。生成後画像の代わりに同じサンプル写真を使用する。既存UIのテスト画像表記をそのまま使用する。
- `geo-candidate.json`: 避難AIの選定理由・未確認事項。実経路に一致した収録地形のIDとカテゴリを差し込み、従来の検証・設問化処理に渡す。架空の地物・道路を追加しない。

部屋の検証は既存の「写真をえらぶ」で `public/figma/img/room-risk.jpg` を選び、通常どおり進む。別の写真を選んでも同じモック結果を返す。写真の実解析ではない旨は既存の警告欄に表示する。

フェーズ2のGoogle Mapsは従来どおり。既存のAPI版にはGoogleキーが必要で、既存のモック版は不要。OpenAIの代替だけをこの環境変数で切り替える。

`.env.local` はアップロードしない。公開先でも使う場合は `OPENAI_MOCK_MODE=true` を設定して再デプロイする。
