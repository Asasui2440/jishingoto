# フェーズ1の写真認識と説明の対応範囲

2026年9月13日時点。写真認識の分類は次の16種類です。1枚につき最大8件の候補を扱います。写真に写った全物体を列挙する仕組みではありません。

| 認識分類 | 対策の説明 | 対策イラスト |
| --- | --- | --- |
| 本棚（bookshelf） | 固定・重い本を下段へ・落下防止の専用説明 | 壁への固定金具と落下防止バー |
| 食器棚（cupboard） | 扉の開放防止・固定・食器の収納の専用説明 | 男性が食器を下段へしまう |
| 棚の上の物（elevated_objects） | 低い位置への収納・棚の端を避ける専用説明 | 収納箱を下段へ移す |
| 背の高い収納家具（tall_furniture） | 棚本体の固定・中身の飛び出し防止の専用説明 | 壁への固定金具と落下防止バー |
| テレビ（tv） | テレビと台の固定の専用説明 | 固定ベルト |
| 窓（window） | 飛散防止・寝る場所との距離の専用説明 | 窓と寝る場所の配置 |
| 出入口・ドア（doorway） | 通路・扉の開閉範囲を空ける専用説明 | 通路の荷物を収納する |
| 吊り下げ物（hanging_object） | 配置・固定の共通説明 | 専用の対策イラストなし |
| 机・テーブル（desk） | 配置・固定の共通説明 | 専用の対策イラストなし。行動クイズには机の下に入るイラストあり |
| ベッド（bed） | 頭上・周辺の家具・枕元の備えの専用説明 | 窓と寝る場所の配置 |
| 床の物（loose_objects） | 通行を妨げる分類なら通路の説明。それ以外は共通説明 | 通路の荷物を収納する |
| 楽器（instrument） | 小型楽器の収納・ピアノやスタンドの機種別対策 | 専用イラストなし |
| 衣類・バッグのラック（clothes_rack） | 掛けすぎ・偏り・通路・適合する固定方法 | 専用イラストなし |
| ペットのケージ（pet_cage） | 落下物を避ける配置・安定・扉・キャリーの備え | 専用イラストなし |
| 洗濯機（washing_machine） | 設置台・ホース・周囲の棚・未使用時の水道栓 | 専用イラストなし |
| その他（other） | 通行を妨げる分類なら通路の説明。それ以外は共通説明 | 通行を妨げる分類なら通路のイラスト。それ以外はなし |

食器棚を除き、名前に「ガラス」と「ドア・扉・戸」を含む対象には、ガラスのドア向けの専用説明・イラストを優先します。専用説明のない分類でも、通行を妨げる判定の場合は通路向けの説明・イラストになります。

## AIが行う部分と教材側で用意している部分

- AIは写真から対象名・分類・転倒落下／破損／通行の妨げの種別・おおよその位置を候補として返します。見落としや分類違いはあり得ます。固定状態や実際の耐震性を判定するものではありません。
- 対策文は分類に応じた事前作成の文章です。子供向け・大人向けを分けています。対象ごとにAIが新しい対策文や説明イラストを生成する実装ではありません。
- 行動クイズは、机・棚上の物・通路などの分岐と、転倒落下／破損／通行の妨げの共通問題を組み合わせます。物の名前と写真上の位置を反映しますが、全対象に独立した専用問題があるわけではありません。キッチン・情報確認などの共通問題も加わります。
- 防災用品は対象分類に対応する事前登録の製品例です。写真から寸法や設置条件への適合を確定していません。

主な実装: `src/app/api/room/analyze/route.ts`、`src/lib/room-guidance.ts`、`src/lib/room-preparation.ts`、`src/lib/recommendations.ts`。


壁掛け・壁内設置と名前から分かるテレビは、壁・金具・施工状態の専用説明を表示し、台置き用ベルトの製品例は表示しません。設置方法不明のテレビには両方の備えを案内します。

## 予想図の生成開始

プライバシー画面のOKでマスクを画像に焼き込んでから、同一の加工済み画像を解析・予想図生成の両方へ送ります。結果はメモリで共有し、リザルトと共有画面で同じ生成結果を使います。生成に失敗した場合はボタンで再試行できます。写真は永続保存しないため、ページ全体の再読み込みで失われた場合は選び直しを案内します。


2026年9月13日 UI追記：説明モードは「小学校高学年向け／大人向け」。子供向けの共有ページはLINE共有と画像保存を表示し、X共有は大人向けにのみ表示します。通常の足元確認と、閉じ込め・移動が危険な場合の救助要請を分けています。ガラスドアの対策画像は飛散防止フィルムを貼る場面です。

コンロは名前から識別し、備えは可燃物の整理・消火器の確認を専用表示します。参照: https://www.tfd.metro.tokyo.lg.jp/lfe/kasai/bouka/konro.html 、https://www.tfd.metro.tokyo.lg.jp/lfe/bou_topic/jisin/sonae10.html 。出題時は部屋の写真、振り返りはキッチンの説明イラストを表示します。
