# jishingoto2の見た目を整理（2026-09-14・初回の調整記録）

この文書は白黒の挿絵を使った初回調整時の記録。現在の配色・挿絵・予想図を先に表示する順序については [TEXTBOOK_UI.md](TEXTBOOK_UI.md) を参照。

土台はGitHub最新版を統合済みのjishingoto2。子供／大人の選択、ホーム、撮影、家具確認、5問のクイズ、1問ずつの振り返り、まとめ、チェックリスト、画像保存・共有の構成を維持した。

- 黄色い主要ボタンと丸いカードはjishingoto2のまま。白・落ち着いた背景色を中心にし、影、補助色、注意書きの装飾を控えめにした。
- ホーム・撮影画面の部屋と、結果の親子・行動の挿絵はjishingoto3の固定素材を再利用。冊子の表紙、章立て、横の目次には変更していない。
- 既存の設問と推奨行動をそのまま使い、図を場面に対応づけた。新しい出口・家族確認・建物から離れる場面・ガス元栓・階段にはシンプルなSVGを追加。コンロと元栓は別々の図で示す。
- 対象物に応じた家具対策の説明画像は維持する。実際の部屋写真、AIの生成する地震後の予想図、サンプル表示も従来通り。
- 予想図の上の「4つのチカラ」は、東京防災風の版を参考に縦2×横2で表示する。得点を大きくし、未出題の項目は「—」と「今回はなし／対象なし」で示す。保存PNGも同じ4分割に合わせ、得点・説明の内容は維持する。

素材は `public/illustrations/handbook/`。4点のPNGは以前のjishingoto3で生成済みのものをコピーした。今回の調整では画像生成APIを呼んでいない。API・認識・生成プロンプト・回答と状態管理のファイルは変更前と同じチェックサムであることを確認した。
