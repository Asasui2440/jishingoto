# 室内体験の実装ガイド

起動手順と全体の流れは [README](../README.md) を参照してください。

## 写真・AI処理・保存

- 通常の入口は `/camera` の写真撮影・動画撮影・フォルダ選択です。`/camera/video` も同じ画面です。選択画像で指定した箇所は画像データ自体をマスクします。顔や住所の自動検出は未実装で、利用者が隠す場所を指定します。
- マスク後に「解析する」を押すと、部屋解析と予想図生成を並行して開始します。写真は同じマスク済み画像、動画は解析に一覧画像・予想図に広く写るマスク済みの1枚を使用します。予想図には画風専用の参考画像 `room-style-reference.jpeg` も添え、細い輪郭線・彩度を抑えた落ち着いたベタ塗り・最小限の影による2Dアニメ調を指定します。部屋の配置はマスク済み写真だけを根拠にします。OpenAIへのリクエストはサーバーのRoute Handlerから送ります。
- 解析中の3段階バーは時間に応じた演出です。約1.4秒ごとに段階が進み、最後の段階で解析完了を待ちます。APIの実際の処理率を示すものではなく、経過秒数も表示しません。
- 解析に失敗すると、警告付きでサンプルの認識結果に切り替わります。予想図の生成に失敗した場合や写真を失った場合は、`aftermath-sample-v3.png` を表示します。画面と保存PNGの両方にサンプルであること・本人の部屋の再現ではないことを明記します。元写真が残っていれば生成を再試行できます。
- 生成結果は同じ写真についてメモリ内で再利用し、結果画面の「あなたの防災4つのチカラ」の下と、共有画面に表示します。生成済み画像を表示するために毎回生成し直すことはありません。
- 写真と生成画像、動画から選んだマスク済みの個別画像はWeb Storageに保存しません。画面を完全に再読み込みすると失われることがあります。回答などの体験状態は `sessionStorage`、表示設定は `localStorage` を使用します。
- 小学生向けはLINE、大人向けはX・LINEで共有できます。共有テキストにはリザルトと同じ行動クイズの点数（初動対応・判断力・避難時の安全性、各5点）と公開アプリのリンクを必ず含めます。未出題の軸は点数を載せません。「予想図も共有する」は初期OFFで、ONなら予想図だけを添付します。サンプルの場合は画像内と共有文で明記します。画像添付は端末・共有先アプリの対応に依存し、非対応の場合は画像保存とテキスト共有の導線を出します。SNSへ自動投稿はしません。
- 画像保存はリザルト画面で行い、4項目のバーと予想図を1枚のPNGにまとめます。SNS共有ページには合成画像のプレビュー・保存ボタンを表示しません。「予想図も共有する」を選ぶと添付用の予想図を準備します。

## 認識・対策・クイズ

認識結果は最大8件です。物体の分類は、本棚、食器棚、棚の上の物、背の高い家具、テレビ、窓・ガラス、出入口、壁掛けの物、机、ベッド、床の物、楽器、衣類・バッグ掛け、ペットケージ、洗濯機、その他に対応しています。写真にある物を必ずすべて認識できるわけではなく、番号や囲みの位置も確認・修正が必要です。

- 対策文と説明イラストは、認識した分類・名称に応じて用意済みのデータから選びます。防災用品も対象物に応じた製品例で、毎回AIが商品を検索して推薦する仕組みではありません。小学生向けには商品購入リンクを出しません。型番付き製品5点は一致を確認したAmazon商品ページへ直接リンクし、型番のない用品だけ検索リンクを使います。設置条件の注意は対策詳細にまとめています。
- クイズは常に5問です。揺れている間の身の守り方は確認した家具に応じて最大2問（対象が少ない場合は1問）、残り3〜4問は揺れた後の場面を出します。机が確認できた場合は最初に優先します。写真の対象に応じた問題を優先し、出口・家族の安否・情報・避難先など、条件を明示した共通問題で補います。コンロは確認結果にある場合だけ出題し、SNSの問題は毎回固定せず、選ばれた場合は5問目に出します。「対策済み」チェックと出題対象の確認は別の状態です。
- 最初の問題では、黒い「揺れが始まりました！」画面を0.7秒表示した後、1.6秒の揺れ演出を入れます。
- 回答を終えてから1問ずつ振り返ります。各問の問題文は振り返りカードの上に全文表示します。カードはイラスト・覚えておきたい行動・左線付きの回答欄・詳細ボタンの順に表示し、安全につながる評価メッセージだけ緑色にします。新しい問題にも対応する行動イラストを用意し、未対応・画像欠落をテストで確認します。安全につながる評価は緑色とチェック、注意が必要な行動は黄色と記号で表示し、正解・不正解とは表記しません。小学生向けは高学年を想定し、「〜しよう」「〜できるよ」の口調にそろえています。詳しい解説はパネルで確認でき、写真にひもづく問題では対象を囲む枠も表示します。
- 「4つのチカラ」は回答から集計する振り返りの指標です。実際の安全性を判定するものではありません。

## 表示設定と端末機能

- 小学生向け・大人向けで文言を切り替えます。ふりがなは両方で利用でき、`漢字[かんじ]` 記法に加えて、注記のない漢字の読みをサーバーのkuromoji辞書で補完します。固有名詞などは誤読や未対応があり得ます。
- 文字サイズを変更できます。文言を必ず1行に収める前提にはせず、大きくした場合の折り返しを考慮します。
- カメラは権限とセキュアな接続（localhostまたはHTTPS）が必要です。利用できない場合もファイル選択やサンプル写真で確認できます。
- 音と端末の振動は設定で切り替えられます。視覚的な揺れには `prefers-reduced-motion` を考慮しています。
- 多言語の設定型はありますが、翻訳辞書は未実装です。

## 動画から画像を選ぶ

- ホームの「体験を始める」から `/camera` に進み、「写真」「動画」の2区分に、それぞれ「撮影する」と「写真から選ぶ」「動画から選ぶ」を表示。写真は `/privacy`、動画はAIによる画像選択へ進みます。動画は1〜60秒・100MBまで。写真・動画ボタンは `getUserMedia` で画面内のカメラを起動します。動画は音声なしで `MediaRecorder` に録画し、開始・終了・取消に対応。カメラ非対応・権限拒否時はエラーを表示し、ファイル選択へ勝手に切り替えません。保存済みファイルは「写真から選ぶ」「動画から選ぶ」で指定し、ファイル選択を画像・動画それぞれに絞ります。
- 一周15秒を撮影ペースの目安として文章で案内。時間ごとの回転量の表は表示しません。両手で持ち、途中で止めずに一定の速さで部屋を見回すよう案内します。15秒は目安のみで、15秒を超える動画も使用できます。撮影速度は実測せず、取り込み時には1〜60秒の長さを検証します。
- 端末内で動画を最大8区間に分け、各区間5枚の輪郭の明瞭さと明るさを比較して1枚ずつ残します。最大40枚を比較しますが、送信する候補は最大8枚。映像全体がブレている場合や模様・ノイズによっては見やすい画像を選べません。
- 撮影・選択後、候補画像を `/api/room/select-frames` 経由でOpenAIへ送り、異なる範囲を補う最大3枚を選択。全候補を確認する手順は省き、AIが選んだ画像から表示します。動画・音声は送信しません。
- 選別時はマスク前の画像を送信します。選択後は「画像の確認・マスク」を表示し、選ばれた1〜3枚を順に確認します。最後の「解析する」を押すまで部屋解析・予想図生成は開始しません。マスクを追加・解除でき、マスクは以降の部屋の解析・予想図・共有に適用します。選別時の送信は取り消せません。動画の選別前のマスク機能はありません。写真の場合は `/privacy` でマスクしてから送信します。
- 「使う画像を選ぼう」の一覧画面は表示しません。AI選択中は進行状況のみを表示し、成功後は直接マスク画面へ進みます。失敗した場合は再試行か動画の選び直しを案内します。画像はページ内メモリにのみ保持します。
- 解析には確定した画像の一覧を使用します。家具を番号順に確認する `/risks` では、その家具に対応するマスク済み画像を1枚だけ表示し、別の画像にある家具へ進むと写真も切り替えます。家具は写真1→写真2→写真3の順にまとめてから通し番号を振り、同じ写真内ではAIの元の順序を保ちます。既に開いている結果も同じ順番で表示し、クイズへ進む際もこの順序を保存します。囲み・マーカーは表示する写真の座標に変換します。クイズ・振り返りも該当写真1枚に枠を変換します。共有用の元写真には一覧を使用します。同じ物体は重複を避けるよう指示します。AIには部屋が最も広く写る候補を先頭に返すよう指示し、その1枚のマスク後の画像から予想図を作成します。パノラマ合成・3D復元はしません。
- 動画の読み込み・比較は端末性能や画質に依存します。スマートフォン実機での速度、実際のAI選択精度は未検証です。

画像入力の仕様：[OpenAI Images and vision](https://developers.openai.com/api/docs/guides/images-vision)。

検証：公開用の最新mainベースで自動テスト45件・Lint・本番ビルド（`npx next build --webpack`）が成功。ブラウザでは候補確認の省略、選択後のマスク、解析へマスク済み一覧画像を渡すこと、AIの応答は模擬APIで確認しています。

撮影方法の選択画面には `room-wide-v7.png` の部屋イラストを表示します。動画のマスク表示は写真と同じアイコン・「ぼかし済」ラベル・画像の下のタップ案内を使用します。

録画は15秒を目安に利用者が終了します。60秒では自動停止します。端末で対応するMP4／WebM形式を選び、録画時間を切り出し処理へ渡すため、録画直後のWebMで長さ情報がない場合にも対応します。音声トラックは取得しません。

画面内カメラの検証：Chromeの模擬カメラで写真撮影→マスク、動画録画→切り出し→マスク、録画取消を確認しました。撮影ボタンではファイル選択が開かず、保存済みファイルを選ぶボタンだけで開くことを検証しています。AI応答は模擬で、実機カメラ・外部AIはこの検証に使用していません。

画像選択の502は、認証・権限・利用上限・接続失敗・40秒の時間切れ・選択結果の形式エラーを `code` と画面文言で区別します。サーバーログはコード・上流HTTP状態・リクエストIDのみで、画像やAPIキーは出力しません。

### 写真を中心にした表示

認識修正は写真の上のパネルから開きます。動画の場合も、対象の写真1枚と番号・囲み枠を表示します。写真番号は画像に重ね、下部には通し番号と対象名を1行で表示します。対策の手順・注意点、クイズの振り返りの詳細はパネルにまとめ、予想図は結果サマリーの4つのチカラより下に表示します。


### 2026年9月14日の表示改善と検証

撮影方法と家具の表示をコンパクトにし、番号や矢印で開いた家具も確認済みとして数えます。全件確認後にクイズへ進み、5問を振り返ります。問題文は振り返りカードの上に全文表示し、選んだ行動は左線付き、評価は緑・黄で区別します。

結果と予想図を1枚に合成する保存はリザルト画面に置き、SNS共有ページは上寄せで点数・アプリURL・任意の予想図添付を表示します。動画AI選別中には豆知識を出しません。予想図の失敗時はサンプルと明記します。

対策の説明イラストは小さく表示し、振り返りのイラストはカード幅に合わせます。火元確認はコンロと元栓を左右に分け、出口・家族・建物からの避難にも対応画像を追加しました。[生成プロンプト・確認記録](ILLUSTRATIONS_20260914.md)を参照してください。

検証：自動テスト106件・Lint・型チェックが成功。写真・動画のカメラ操作、家具確認、保存PNGの構成を確認しました。追加画像は生成後に目視確認しています。アプリ内ブラウザーではPNG表示を確認しましたが、ダウンロード完了イベントは未確認です。端末・共有先アプリによる保存や添付の違いは残ります。

動画選別APIとマスク済み画像・画風参照画像の送信は模擬APIで検証し、今回の最終確認では実APIによる画像生成は再実行していません。外部SNSへの投稿も行っていません。

本番ビルドは `npm run build -- --webpack` で成功し、予想図APIの成果物に画風の参考画像が含まれることを確認しました。通常のTurbopackビルドは、この作業フォルダの外を参照する `node_modules` のリンク制約で失敗しています。
