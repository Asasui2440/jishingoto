# 挿絵の統一・落ち着いた評価表示・ホームへの移動（2026-09-14）

## 画面

題名を「ジシンゴト！」に統一。表紙の題名は茶色（`#5d4612`）。背景は以前の黄色・黒版の `#f8f7f0` に戻した。4分割の評価は項目ごとの色分けをやめ、白い背景 `#ffffff` と黄色い割合バー `#ffcf3f` を使う。区切り線はページ背景と同じ色にした。画面と保存PNGで同じ配色を共有している。

jishingoto2の構成と黄色の主要ボタン、左だけ太い枠を使わない詳細行は維持。結果のまとめは「地震後の予想図 → 2列×2行の4つのチカラ → 1枚で保存」。PNGも同じ順序。得点・「今回はなし／対象なし」の計算条件は変えていない。

## 挿絵

ホームの [部屋の挿絵](../public/illustrations/textbook/room-v3.webp) を基準に、人物の顔・髪・体形、細い輪郭、平坦で控えめな塗りを統一。ごく小さい線の揺れ・かすれは残し、写実的な陰影や細かい髪の描写を外した。

描き直したものは、情報確認・家族への声かけ・出口確認、家具の対策5枚、避難2枚、家族との合流。用品と部屋の図解も同じ方向で整理し、SVGの太い線と丸いチェック飾りを外した。参考画像の人物や構図をそのまま使っていない。AIで制作した固定素材で、実際の手描き原画ではない。

- [今回の生成プロンプトと元PNG](../outputs/illustration-proposals/20260914-unified/prompts.json)
- [現在使用する31素材の一覧](../outputs/illustration-proposals/20260914-unified/active-assets.json)

表示素材は21枚のWebPと10枚のSVG、合計約1.25MB。表示するたびに画像生成APIは呼ばない。写真や地震後の予想図は、この説明イラストとは別に扱う。
