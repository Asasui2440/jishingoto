# 挿絵の統一・落ち着いた評価表示・ホームへの移動（2026-09-14）

## 画面

題名を「ジシンゴト！」に統一。表紙の題名は茶色（`#5d4612`）。背景は以前の黄色・黒版の `#f8f7f0` に戻した。4分割の評価は項目ごとの色分けをやめ、白い背景 `#ffffff` と黄色い割合バー `#ffcf3f` を使う。区切り線はページ背景と同じ色にした。画面と保存PNGで同じ配色を共有している。

jishingoto2の構成と黄色の主要ボタン、左だけ太い枠を使わない詳細行は維持。結果のまとめは「地震後の予想図 → 2列×2行の4つのチカラ → 1枚で保存」。PNGも同じ順序。得点・「今回はなし／対象なし」の計算条件は変えていない。

## 挿絵

ホームの [部屋の挿絵](../public/illustrations/textbook/room-v3.webp) を基準に、人物の顔・髪・体形、細い輪郭、平坦で控えめな塗りを統一。ごく小さい線の揺れ・かすれは残し、写実的な陰影や細かい髪の描写を外した。

描き直したものは、情報確認・家族への声かけ・出口確認、家具の対策5枚、避難2枚、家族との合流。用品と部屋の図解も同じ方向で整理し、SVGの太い線と丸いチェック飾りを外した。参考画像の人物や構図をそのまま使っていない。AIで制作した固定素材で、実際の手描き原画ではない。

## 終了演出と人物の行動

クイズ終了の約3秒の演出は、通常画面と同じ黄みのある背景・茶色の見出しに統一。ホームの親子イラストが現れ、黄色の波形が落ち着き、見出しの下線が伸びる。スキップボタンは表示せず、約3秒で自動的に振り返りへ進む。動きを減らす設定では省略し、Escapeでも閉じられる。最後の回答を保存した後に表示し、再訪では繰り返さない。

物だけだった10種類の図を、行動する人物が見える挿絵に変更。出口確認・危険な建物から離れる・コンロ・元栓・ベッド・コピー機・階段・職場待機の8枚を内蔵の画像生成で制作。高台避難と在宅での情報確認は、同じ画風の既存素材を再利用した。火や元栓の操作は大人が行う姿で描き、設問の「揺れが収まり、安全に近づける場合だけ」の条件を継続して表示する。

- [人物入り素材と生成プロンプト](../outputs/illustration-proposals/20260914-people-actions/prompts.json)
- APIなしの確認ページに「クイズ終了の演出を試す」「人物入りのイラストを試す」を追加。確認ページはローカル専用。本番は既定で404、Vercelは常に404。ローカルの本番ビルド検証のみ、起動時に `ENABLE_LOCAL_TEST_PAGES=1` を指定できる。

## 行動の振り返り

質問文と自分が選んだ回答を、同じカードの上部で続けて確認できるようにした。回答は薄い黄色の背景で強調し、実際に表示された選択肢の番号と補足も載せる。その下に推奨行動の挿絵と振り返りのポイントを表示。時間切れは「時間切れ・未回答」と明記し、自動的に割り当てられた選択肢を本人の回答として表示しない。
