# 残り20問のV2画像：制作結果

通常問題の残り20問について、状況1枚と選択肢3枚を各問ごとに生成し、80枚を追加した。既存40枚と合わせて全30問120枚が揃った。太い濃紺の輪郭、青い服と黄色いリュック、少ない背景を基準に制作した。

画像制作後、全30問120枚をゲームに組み込み済み。問題IDと選択肢IDで画像を紐づけた。本文・採点は変更していない。各組のレビューは制作時点の記録として残している。固定練習用のwall・fall・closed・practice-floodはこの30問に含まれない。

## 検証結果

- 全30問について、situationと正本から転記したchoiceIdの計120ファイルが存在することを確認。新規80枚の保存先に重複なし。
- 全120枚が960×640pxのWebPで、画像デコードに成功。合計3,523,242バイト、新規80枚は2,480,728バイト。
- 新規80枚の生成記録にある元PNGと参照画像の存在を確認。
- 生成画像と7組の縮小比較シートを目視確認。画像・制作記録のみの変更のため、アプリのテストとビルドは再実行していない。

## 組み込み時の確認点

組み込み後の検証：全30問の状況・選択肢を逆順で描画し、120枚のローカル画像への対応とファイルの存在を確認。固定練習・未知の問題のSVGフォールバックもテスト済み。問題9・18・28・38の4枚表示と読み込み、確認中の時計停止を画面幅390・360・320pxで検証し、E2E 15件が成功した。縮小画面のスクリーンショットも目視確認した。TypeScript型検査と変更したコードのESLintは成功。

待機や情報確認の細かな意図は選択肢文を併用する。特に問題32・35などは場所の関係を残すため人物が小さめで、実画面での表示サイズを再確認する。問題26・37などは視点や背景配置に差があり、全画像で背景を厳密には固定できていない。個別の制約は各組のレビューに記載した。

画像は `public/illustrations/evac/walk-case-番号/{situation,choiceId}-v2.webp` に保存。内蔵画像生成で1枚ずつ制作し、元PNGからWebP（品質85）へ変換した。元PNGの保存先と実際の指示は各 `batch-XX-prompts-v2.json` に記録している。
