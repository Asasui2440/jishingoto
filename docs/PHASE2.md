# フェーズ2：ひなん経路シミュレーション

自宅付近から避難場所までの**実在する経路**を題材に、地震後の街中で起こり得る危険に対して
判断し、経路を選び直す体験。フェーズ1（部屋の中）の続きにあたる。

## 画面の流れ

| ルート | 内容 | 仕様の対応 |
|---|---|---|
| `/evac` | 自宅付近の指定・避難場所の確認 | 3-①② |
| `/evac/routes` | 徒歩の候補経路2本の比較・制限時間の設定 | 3-③④、5 |
| `/evac/walk` | ストリートビュー上の判断（2〜3件） | 3-⑤⑥⑦、6、7 |
| `/evac/report` | 結果レポート | 3-⑨、8 |

入口はトップ（`/`）の「ひなん経路をためす（フェーズ2）」。

## Google Maps Platform

`.env.local` に置く：

```
NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=...
```

有効にする API：**Maps JavaScript API**（地図・Street View・Directions を含む）。
キーには HTTP リファラ制限をかけること。

**キーが無くても動く。** 地図は簡易マップ、ストリートビューは自作イラストに切り替わり、
経路もデモ用に合成したものになる（仕様 13：本番の画像を使えない場合は同じ UI でデモする）。

### 使っている API

| 用途 | いま | 差し替え先 |
|---|---|---|
| 地図・現在地 | Maps JavaScript API | そのまま |
| パノラマ探索 | `StreetViewService.getPanorama()`（緯度経度＋半径80m、屋外のみ） | Street View Static API Metadata でも可 |
| 徒歩経路・代替経路 | `DirectionsService`（`provideRouteAlternatives`） | サーバー側で **Routes API** を叩く形に置き換え可（`fetchRoutes()` の中身だけ） |
| 避難場所 | `evac-content.ts` のデモデータ | 自治体オープンデータ（指定緊急避難場所・指定避難所） |

## バックエンドをつなぐとき

差し替えるのは `src/lib/evac-api.ts` の中身だけ。

export async function fetchShelters(near: LatLng): Promise<Shelter[]>

## 守っているルール

### 安全表現（仕様 11）
- 実在の建物・塀・道路が壊れると**断定しない**。危険はすべて「〜した想定」と書く。
- 画面上部に「想定シナリオ」の帯を**常時**出す（`/evac/walk`）。
- ストリートビューの上に重ねるのは、半透明の想定範囲と番号だけ。
  実在の建物が損壊して見える加工はしない。
- 「現在のストリートビュー画像だけでは安全性を判定できません」を下部シートに常時出す。
- 経路の説明に「安全です」と書かない。距離・時間・イベント数・曲がる回数など、
  **経路データから言えることだけ**を並べる（`routeNotes()`）。

### データの扱い（仕様 9）
- ストリートビューの画像はアプリ側で保存・キャッシュしない。
- パノラマ ID に依存せず、毎回 緯度経度から `getPanorama()` で取り直す。
- 保存するのは、指定した地点・選んだ避難場所・経路の座標・イベント ID・回答だけ
  （`jishingoto.evac.v1` / `sessionStorage`）。
- 位置情報の使いみちを `/evac` で先に説明する。

### 帰属表示（仕様 7・14）
- Street View のコントロールは減らしているが、**住所表示と Google のロゴは消さない**。
- 下部シートはパノラマの**外**に置き、パノラマの下端に何も重ねない。

### AI とルールエンジンの分担（仕様 10）
- 判断イベントの中身・選択肢の優先順位は `evac-content.ts` の**ルールデータ**。
  ストリートビューの画像を見て判定してはいない。
- ストリートビュー画像を AI に送る解析は、利用条件と権利処理を確認したあとの将来機能。

### 判断と結果（仕様 6・8）
- 選択は3択（そのまま進む／距離を取る・待つ／迂回する）。正解を当てるクイズにしない。
- 選択直後は短いフィードバックだけ。利点と注意点は結果レポートでまとめて出す。
- 迂回を選ぶと、この先の判断地点が別ルートのものに差し替わる。
- 結果は点数を主役にせず、「避けられた危険」と「次回の判断基準」、
  そして**平常時に確認すること**をひとつ選んでもらう形にしている。
- 制限時間は既定10秒。シートから「＋10秒」「なくす」、`/evac/routes` からも変更できる。
  時間切れは「迷っているうちにそのまま進んだ」として扱い、安全な選択を自動では選ばない。

## ハッカソン版の範囲（仕様 13）

- 対象地域：文京区大塚 付近（デモ）
- 避難場所：2か所（`DEMO_SHELTERS`）
- 候補経路：2本
- 判断地点：最短ルート3地点／もう一方2地点
- イベント：ブロック塀・落下物・通行止め（各3択）
- 結果レポート：1画面

## まだ入っていないもの

- ハザードマップ（対象災害に応じた補助情報）の重ね合わせ
- 避難場所が利用できない想定への分岐
- 夜間・雨天の想定
- 成功指標の計測（イベント送信）
