# ジシンゴト！

部屋の写真や動画から地震への備えを考える防災体験アプリ。**子供向け・大人向け**の表示に対応しています。入口（`/`）は「子供」「大人」を選ぶ専用画面です。選択後は対象に応じたホーム（`/home`）へ進み、「体験を始める」で撮影・写真／動画選択画面（`/camera`）を開きます。ホームの「えらびなおす」で選択画面に戻れます。

| 体験 | 流れ |
|---|---|
| フェーズ1：室内 | 写真・動画の撮影／フォルダから選択 → 画像の確認・マスク → 家具・対策の確認 → 行動クイズ → 振り返り・予想図の共有 |
| フェーズ2：避難経路 | 出発地点・避難場所の選択 → 経路比較 → Street View／地図で行動判断 → 振り返り |

通常の避難経路のAPI体験は、接続確認済みのStreet Viewを8ノード進むごとに出題します。問題数の上限はなく、迂回後も8ノードごとに続きます。短い経路でも体験全体で最低3問になるように配置し、地点が足りない場合は同じ地点で順に出題します。到着地点の問題は回答後に完了します。歩行中の想定問題30種類は、状況と優先順位を考える3択で、表示順は毎回変わります。共通問題を使い切った長い経路では、一巡ごとに再利用します。問題は状況図1枚と行動図3枚で比較できます。問題表示と同時に回答・時間計測を開始します。Street Viewや詳しい説明を確認している間は時計が止まり、設定から時間制限なしにも切り替えられます。固定のモック・サンプル体験は従来の練習用配置です。

避難体験のクイズは画面を広く使い、小さい画面では状況図と説明を横に並べます。到着するとStreet Viewに白いオーバーレイと終了表示を重ねます。振り返りは白地・黄色い枠のリング状スコアと、小さな状況イラスト付きの判断一覧を表示します。判断は○・△・×と行動カードの背景色で見分けられ、気になる場面だけポップアップでイラストと理由を確認できます。状況図と条件文を強調したカードで示し、比較する行動画像の位置と高さを揃えます。地図・スコアのどちらから開いても推奨行動を横に比較表示します（選んだ行動が最優先の場合は重複表示しません）。最後の判断では「判断を閉じる」で一覧へ戻れます。利点と注意点はラベル付きのタブで切り替え、内容が細い帯へ縮んでから開く動きを付けています。動きを減らす設定では即時に切り替わります。全判断を順番に開く必要はありません。「振り返りを終わる」を押すと次の備えを選ぶポップアップが開き、その後にルートの端末保存・別ルートへの再挑戦・トップ（`/home`）へ戻る画面へ進みます。保存は通過経路と選んだ備えを含むGeoJSONファイルのダウンロードです。地点確認中は処理段階の進捗バーと取得済み地点数を表示します。訓練の前提は共通の説明にまとめ、各場面名の「想定」は省いています。長文や文字拡大時は内容をスクロールできます。

ふりがな・文字サイズ・音と振動を設定できます。AIの認識・予想図や経路表示は、実際の被害や安全性を保証するものではありません。

## ロゴ

入口・ホーム・結果のブランド表示には、茶色と黄色の文字ロゴと、薄い黄色をベースにした線画の丸いマークを使います。既存の挿絵に合わせ、文字の角と表示サイズをやわらかく調整しています。透過PNGは `public/brand/wordmark-v7.png` と `public/brand/symbol-v6.png`、表示は `src/components/Brand.tsx` にまとめています。文字の亀裂と水面、家の中の「！」はロゴの意匠です。洪水体験の機能追加ではありません。

## 起動

**Node.js 20.9.0以上・npm**が必要です。

```bash
npm ci
cp .env.example .env.local  # 初回のみ。既存ファイルは上書きしない
```

`.env.local` にキーを設定して起動します。

```bash
npm run dev
```

[localhost:3000](http://localhost:3000) を開いてください。環境変数を変更したらサーバーを再起動します。

室内体験を別サーバーで確認する場合は `ROOM_DEV_SERVER=1 npx next dev --webpack -p 3001` を実行し、[localhost:3001](http://localhost:3001) を開きます。出力先は `.next-room-dev/` になり、通常の `.next/` を使う開発・ビルドと分離します。起動中の出力先を削除・上書きするとChunkLoadErrorの原因になります。サーバーを切り替えた後はページを再読み込みしてください。

### 環境変数

`.env.local` は `package.json` と同じ階層に、各メンバーが作成します。

| 変数 | 用途 |
|---|---|
| `OPENAI_API_KEY` | 部屋の画像解析・予想図生成。**発行されたキー本体**を設定 |
| `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` | フェーズ2の地図・Street View |
| `OPENAI_VISION_MODEL` | 任意。解析・生成後の比較モデル（既定：`gpt-5.6-luna`） |
| `OPENAI_IMAGE_MODEL` | 任意。生成モデル（既定：`gpt-image-2`） |
| `OPENAI_IMAGE_QUALITY` | 任意。`low`／`medium`（既定）／`high`。画質・待ち時間の比較用 |
| `OPENAI_IMAGE_SIZE` | 任意。`1536x1024`（既定）／`1152x768`（同じ横縦比の軽量版） |
| `GOOGLE_MAPS_SERVER_KEY` | 任意。サーバー経由の経路取得 |

OpenAIキーはサーバー専用です。`NEXT_PUBLIC_` を付けず、キーや `.env.local` をGitに追加しないでください。Google MapsのAPI・キー制限の設定は [.env.example](.env.example) を参照してください。

室内の危険確認（`/risks`）では、危険の理由と対策を読み、写真の左右端に重ねた矢印で1か所ずつ確認します。矢印・別の番号・画面下部の「次へ」は、いま表示している項目を確認済みにしてから移動します。最後の項目は写真右端の「完了」でも下部の「確認を終える」でも確認を終えられます。番号を飛ばした場合は未確認の項目へ戻ります。進捗と残り件数を表示し、全件の確認後は黒いオーバーレイ付きの完了パネルで「行動クイズへ」を強調します。「もう一度見る」やEscapeで戻っても、クイズへのボタンは下部に残ります。家具検出画面の「対策済み」チェックは表示しません。説明部分はスクロールでき、広い画面では写真と説明を横に並べます。

家具を写真ごとに確認し終えると、5問の行動クイズに進みます。揺れている間は確認した家具に応じて1〜2問、残りは揺れた後の問題を出題します。SNSの「このあと大きな地震が来る」という問題を出題しません。SNS共有にはクイズの点数と公開アプリのリンクを入れ、予想図の添付は選べます。リザルト画面では予想図を先に、その下に縦2×横2の4項目を表示し、同じ順序で1枚の画像に保存できます。

大人向けの室内クイズは、短い問いと4択です。「裸足。靴はガラス片の向こう」など、必要な条件を問題文にまとめ、選択肢には補足文を重ねません。全5問、初動20秒・揺れた後25秒で、選択肢の順は毎回変わります。全問後の振り返りに「判断の決め手」と、選んだ行動の注意点を表示します。小学生向けは従来の3択です。ローカルの `/test-room` の「大人向けの4択クイズを試す（APIなし）」から確認できます。

予想図はマスク済み写真と画風の参考画像から、彩度を抑えた落ち着いた2Dアニメ調で生成します。生成に失敗した場合や写真が失われた場合は、サンプルと明示した予想図を表示し、結果と一緒に保存できます。部屋の解析待ちには14種類の防災豆知識を表示します。

予想図の条件は**震度6強**です。固定が確認できない家具は未固定を仮定し、本棚・背の高い収納の転倒、椅子の横倒し、机の移動（不安定な形状なら転倒）、見える収納物の散乱を生成指示に含めます。実際の固定状態や被害を判定するものではありません。[気象庁の震度解説](https://www.jma.go.jp/jma/kishou/know/shindo/kaisetsu.html)と[東京消防庁の熊本地震の室内被害資料](https://www.tfd.metro.tokyo.lg.jp/lfe/bou_topic/kaguten/measures_house.html)を参考にしています。資料の写真自体は生成APIへ送りません。

認識は家具や実害につながる対象を優先し、空の紙コップなど明らかに軽く実害の乏しい小物、危険の根拠がないカップ類は候補から省くよう指示します。割れ物などの根拠が見える場合は対象にできます。物体ごと・リザルト画面の対策済みチェックボックスは廃止し、対策の説明を読む形にしています。リザルトでは「物体ごとの備えを振り返る」から対策を確認できます。結果共有の「戻る」「フェーズ2へ」はコンパクトな2列ボタンです。

机・棚・台の上にある物は、認識時に支持面も取得し、落下の問題文・対策・結果の説明に反映します。天板や棚の構造が見えない場合は「置かれた場所から」とし、ノートパソコンなど物の種類だけで机と断定しません。家具確認の修正画面で置き場所を手動修正できます。認識の精度は未測定です。置き場所の連携・SNS問題の除外を含む関連テスト51件、型チェック・変更ファイルのESLintを通過し、共有ページ・共有JavaScript・クイズのHTTP 200を確認しました。

部屋の認識では家具・家電などの備えを優先し、少量のティッシュ・空の紙コップ・柔らかい小物など、見える状態で明らかに実害の乏しいものは対象から外します。棚の上にあるだけでは採用せず、割れ物・刃物・高所の鉢などは小さくても根拠があれば対象に残します。AIに確認対象かどうかと理由を返させ、対象外の項目はサーバーでも除外します。対象がなければ0件のまま進めます。物の名前だけの一律除外は行いません。固定状態が不明な家具は確認対象に残し、除外を安全性の保証とは扱いません。既存の認識記録には遡って適用せず、新しく写真を解析した結果に反映します。

部屋の認識には、マスク済みの写真を最大3枚、個別の画像として1回のAPI呼び出しに渡します。動画の一覧画像への縮小による細部の欠落を避け、写真ごとの観察根拠・分類・囲み枠を構造化して受け取ります。誤認識の改善幅は実写での比較が必要です。検証手順は [写真認識の対応範囲](docs/ROOM_RECOGNITION_COVERAGE.md) を参照してください。

画像生成は、家具の確認・修正を終えてクイズへ進んだ時点で開始します。元の部屋の構図を保ち、確認した家具の種類・位置に応じて変化を指定します。生成後は元写真とAIで比較し、大きな構造変更・物の追加・マスク領域の描き変えを検出した画像は表示せず、手動で再試行できます。比較できなかった場合はその旨を表示します。通常は画像編集1回と比較用のResponses APIを1回使用します。一時的な混雑による拒否（429・503）のみ、短い待機後に画像編集を最大1回再試行します。タイムアウトや画像の不一致では自動で再生成しません。被害の物理的な正確さや改善幅は、実写での評価が必要です。

全問回答後は、ホームと同じ親子イラストが現れ、黄色の波形が静かに落ち着く約3秒の演出を挟みます。背景・見出しも通常画面と同じ色に統一しています。スキップボタンは表示せず、自動で振り返りへ進みます。端末の動きを減らす設定では演出を省略し、キーボードのEscapeでも閉じられます。追加の画像生成や効果音はなく、生成中・生成失敗でも進めます。結果を再度開いたときは繰り返しません。各問の振り返りでは、質問と選んだ行動（選択肢の番号・補足）を先にまとめ、続いて推奨行動の挿絵と解説を表示します。時間切れは未回答と明示します。行動を1問ずつ振り返ってから、予想図・4つのチカラ・画像保存、室内の備えへ進みます。

jishingoto2の黄色いボタン・丸いカード・画面の流れを残し、ホーム・撮影・対策・結果に、白地と微細な線の揺れを使った固定の説明イラストを使用しています。画面は黄みのある白を背景に、濃い文字でメリハリをつけ、詳細ボタンを下線で区切る形にしています。4分割評価の色は同色に統一しています。写真認識・予想図生成の処理とは独立した表示変更です。[UI調整の内容](docs/TEXTBOOK_UI.md)を参照してください。

## 画像生成と画面幅

フェーズ1で出題される全選択肢に、淡い青を基調にした固定の行動イラストを添えています。現在の出題対象は大人向け9パターン・36選択肢と、子ども向け30種類の選択肢で、同じ行動は共用します。写真・問題文・縦並びの選択肢を保ち、文字の左に56pxの絵を表示します。絵の追加で画像生成APIは呼びません。制作プロンプト・修正記録は `outputs/quiz-illustrations-20260915/`、表示用WebPは `public/illustrations/quiz/` に保存しています。

画像編集は `gpt-image-2`、1536×1024、通常画質（medium）とJPEG出力（85）を既定にしています。元の部屋・対象家具・マスクを保つ指示と生成後の比較は継続します。生成の合計期限は175秒、比較は最大25秒とし、結果画面にクイズ中からの経過時間を表示します。入力・出力ともbase64文字列に容量上限を設け、通信・混雑・利用上限を区別して案内します。

スマホ、タブレットの縦横、分割画面、PCに合わせて本文幅が変わります。本文幅が640px以上ではクイズの写真と選択肢、振り返りの画像と説明を2列にし、狭い画面では縦に戻します。文字サイズ・ふりがなの設定はそのまま使えます。設定と詳細パネルもタブレット幅に対応しています。詳細ポップアップの右上は「×（閉じる）」で、閉じると元の画面と開いたボタンに戻ります。
待ち時間の比較には `OPENAI_IMAGE_QUALITY=low`、解像度の比較には `OPENAI_IMAGE_SIZE=1152x768` を指定できます。画風の参照画像と元写真の比較はどちらの設定でも使用します。細かい家具やマスクの再現性を確認して採用してください。設定変更後はサーバーの再起動が必要です。

スマホ、タブレットの縦横、分割画面、PCに合わせて本文幅が変わります。本文幅が640px以上ではクイズの写真と選択肢、振り返りの画像と説明を2列にし、狭い画面では縦に戻します。文字サイズ・ふりがなの設定はそのまま使えます。設定と詳細パネルもタブレット幅に対応しています。

実測と制約は [生成速度・画面幅の検証](docs/PERFORMANCE_RESPONSIVE.md) を参照してください。

## APIなしで試す

[/test-room](http://localhost:3000/test-room) はローカル確認専用です。開発サーバーでは利用でき、本番では既定で404、Vercelではプレビュー・本番とも404になります。ローカルで本番ビルドを確認する場合だけ、起動時に `ENABLE_LOCAL_TEST_PAGES=1 npm run start` を指定します。確認用コードはGitに保存しますが、APIキーは含めません。このページで、固定の写真・解析結果を使って室内体験を確認できます。「結果ページを試す」からクイズを省略して表示確認できます。「クイズ終了の演出を試す」で結果に入る場面転換も確認できます。「人物入りのイラストを試す」では、出口・キッチン・ベッド・職場などの挿絵を順番に表示できます。予想図はサンプルと明記した固定画像を表示するため、API経由の精度検証ではありません。OpenAI APIは呼びません。フェーズ2は「遊び方・設定」でモック版／API版を切り替えます。モック版はキー不要です。

`/camera` は「写真」「動画」に分け、それぞれ画面内カメラでの「撮影する」と、保存済みの「写真から選ぶ」「動画から選ぶ」を表示します。動画の場合は端末内でブレの少ない候補を最大8枚切り出し、AIが最大3枚を選びます。予想図には部屋が広く写る1枚をマスク後に使用します。家具は写真ごとに連続して番号を振り、対応する写真を1枚ずつ表示します（一定の速さで一周15秒が目安、取り込みは1〜60秒・100MBまで）。

通常の写真解析・予想図生成にはOpenAI APIの利用が発生します。写真はマスク後に送信し、動画のAI選別は**マスク前の候補画像**を送り、選択後のマスクは部屋の解析・予想図・共有に反映します。写真と生成画像はWeb Storageに保存しないため、再読み込みで失われる場合があります。

## 建物名・駅名・住所の検索（Places UI Kit）

出発地点の検索はGoogle **Places UI Kit**の `PlaceSearchElement` / `PlaceTextSearchRequestElement` を使用します。入力して検索ボタンを押すとGoogle提供の候補一覧を表示し、選んだ候補の座標を使います。Googleの帰属表示を含むネイティブUIをそのまま表示し、通常のGeocoding API・Places APIへのフォールバックは行いません。別の同名施設を選ばないよう、候補の所在地を確認してください。

既存のブラウザ用キーのGoogle Cloudプロジェクトで **Places UI Kit API (`placewidgets.googleapis.com`)** を有効化し、キーのAPI制限にも追加してください。通常のPlaces API (New)の有効化だけでは使えません。追加npm依存はありません。通信失敗・API設定不足・検索タイムアウトは画面に表示し、再検索できます。

検索元・取得時刻・30日後の期限を記録します。保存用地図にも元の期限を引き継ぎ、再保存で延長しません。期限後の新規保存を拒否し、保存済みマップは次回読み込み時と起動中の定期確認でIndexedDBから削除します。Webアプリが閉じている間は削除処理を実行できないため、厳密な時刻での端末内消去を保証する方式ではありません。検索結果の名前・住所は永続保存せず、画面の地点ラベルにはユーザーの入力を使用します。旧検索・Google地図のタップなど取得元が対応しない地点から新しく保存する場合は、検索か現在地での再選択を案内します。既存の取得元情報のない保存マップは自動削除・変換しません。

#### 回答直後の解説（実装済み）

行動を選ぶとすぐに「回答と解説」を表示します。選んだ行動の○・△・×の評価と理由、その条件で最も優先したい行動、判断のヒントを確認できます。到着後の振り返りと同じ状況・行動イラストを表示し、より優先したい行動がある場合は選んだ行動と横に並べて比較できます。既存の「利点／気をつけたい点」の切り替えも使えます。解説を閉じるまで自動歩行・次の出題・到着表示を待機し、「歩行を続ける」で再開します。通常のStreet View・地図をつなぐ歩行・モック版に対応しています。

迂回を選んだ場合も通信完了を待たずに解説を表示し、経路を確認できた後に先へ進めます。取得に失敗した場合は、解説内の「回答を選び直す」から戻れます。到着後の振り返りにも回答を残します。

制限時間は残り5秒から黄色・揺れ・波紋で強調し、残り3秒から赤に変わります。確認や設定で時計が止まっている間、また時間切れ後は演出も止まります。端末の動きを減らす設定にも対応します。

避難クイズの制限時間は15秒・25秒から選べます。問題中に変更すると選んだ秒数で再開し、次の問題にも設定を引き継ぎます。全画面の右上に共通の丸いホームアイコンを表示します。「トップへ」などの重複する文字ボタンは表示しません。
